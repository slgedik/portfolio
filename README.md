# 🌐 Personal Portfolio Website

This is my personal portfolio website built with **React** and **TailwindCSS**, deployed on **Netlify** with a custom domain.  
It showcases my projects, skills, and experience in a clean, modern UI.

### Features

- Responsive UI built with TailwindCSS
- Light/Dark mode toggle
- TR / EN language switch
- Background video with blur overlay
- Hero section with CV download button
- Fully deployed to a custom domain using Netlify DNS
- GitHub → Netlify continuous deployment

## 📦 Installation & Setup

Clone the project:

```bash
git clone git@github.com:slgedik/portfolio.git
cd portfolio
```
Install dependencies:
```bash
npm install
```
Run development server:
```bash
npm run dev
```
Build production version:
```bash
npm run build
```
